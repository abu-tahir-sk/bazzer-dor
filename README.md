# BazarDor

(BazarDor) is a modern, responsive web application that tracks and displays real-time market prices of daily essential commodities. Built for a seamless user experience, it helps users make informed purchasing decisions.

##  Technologies Used
- **Next.js (App Router)** - Framework for building the UI and handling routing.
- **Tailwind CSS** - For beautiful, responsive styling matching the design system.
- **TypeScript** - Ensures type safety and robust code quality.
- **BetterAuth** - Provides seamless Authentication including Email/Password and Social Login (Google & GitHub).
- **MongoDB** - Stores authentication data securely.
- **Vercel** - Deployment platform for fast and reliable hosting.

## Key Features
1. **Real-time Price Tracking:** View the latest prices of essential commodities with trend indicators (up/down/flat) and percentage changes.
2. **Category-wise Filtering & Sorting:** Browse products by categories (Rice, Fish, Meat, Vegetables, etc.) and sort them by price (High-to-Low or Low-to-High).
3. **Comprehensive Market Comparison:** Product detail pages show minimum, maximum, and average prices across different divisions and markets, as well as historical prices (yesterday, last week, last month).
4. **Secure Authentication:** Users can securely sign up or log in using email/password, Google, or GitHub via BetterAuth. Certain routes (like product details) are protected for logged-in users only.
5. **Profile Management:** Users can view their profile and update their personal information seamlessly.
